## Tentang Kami

**Kodya Code** adalah tim *software engineer* dan *product builder* yang berfokus pada pengembangan perangkat lunak kustom (*custom software development*) dan kolaborasi teknis jangka panjang. Kami menggabungkan kecepatan eksekusi, standar *clean code*, serta pendekatan rekayasa perangkat lunak modern untuk mengubah ide bisnis menjadi produk digital yang siap produksi.

---

## Layanan & Fokus Pengembangan

- **Custom Web Application Development** — Membangun sistem informasi perusahaan, dashboard analitik, ERP/CRM internal, hingga platform SaaS berbasis web.
- **High-Performance Backend & API Engineering** — Perancangan arsitektur RESTful API, microservices, integrasi *payment gateway*, dan otomasi sistem berkecepatan tinggi.
- **Cross-Platform Mobile App Development** — Pengembangan aplikasi Android dan iOS dengan performa natif menggunakan satu basis kode yang efisien.
- **Technical Partnership & Dedicated Team** — Kerja sama pengembangan proyek bersama agensi, startup, maupun perusahaan yang membutuhkan dukungan tim *engineer* berpengalaman.
